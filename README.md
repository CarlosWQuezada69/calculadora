# Calculadora Web Moderna

## Descripción
Una calculadora de escritorio y móvil con diseño minimalista, efectos glassmorphism y soporte completo para teclado físico.

### Funcionalidades
- Operaciones aritméticas básicas: suma, resta, multiplicación, división.
- Decimales, porcentaje, reset (C), borrado último dígito (CE/backspace).
- Responsive, centrada en pantalla, accesible (`aria-label`, `role="application").
- Implementada con HTML5, CSS3 (Grid/Flexbox, transiciones suaves) y JavaScript vanilla.

## Instalación
Solo abre el archivo `index.html` en tu navegador.
